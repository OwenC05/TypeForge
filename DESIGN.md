## Brand
Quiet, precise, encouraging. Trust comes from working controls and inspectable evidence, not AI spectacle. Avoid fake progress, exaggerated improvement claims and dashboard clutter.
## Product goals
Comfortable, uninterrupted 15/30/60/120-second typing (default 60), direct General/Recommended/Manual practice, and a reproducible ML experiment. Core experience quality rather than competitor feature parity. No cross-passage document editing, unbounded unique content, new model/scorer or accounts/cloud sync in this local change. Public release remains a separate gate.
## Personas and jobs
Everyday physical-keyboard typists assess and practise; technical reviewers inspect provenance, evaluation, deployment and limitations without interrupting the main flow.
## Information architecture
Home/navigation → assessment or direct Practice chooser → timed flow → result → practice or compatible fresh retest. General is always available; Recommended explains unavailable evidence; Manual lists supported within-word pairs. Progress reopens local sessions and labels duration/interaction buckets. Persistent ML Lab navigation separates technical evidence from typing. Lab leads with primary metrics and uncertainty, then source/cohort and secondary checks; raw report JSON stays collapsed.
## Design principles
Native editing over custom editors; readable evidence over decoration; honest empty states over samples. One integrated typing region, not a separate answer bar. Space advances a passage after the expected nonempty word count is reached, even with mistakes; Enter is an explained no-op. Only the current passage is editable. Keep character-based scoring and isolate new flow from legacy Enter and different-duration comparisons. A rolling finite corpus is not a promise of novelty.
## Visual language
Navy #0a111b background, #101b29 panels, teal #6ee7d0 emphasis, #e9eff6 text, #a0afc1 secondary text. System sans and local monospace. 8px-based spacing, thin borders, modest rounded corners. No remote fonts or imagery. Motion is nonessential.
## Components
Shared header/footer, buttons, duration selector, practice/pair chooser, metric cards, explanation panel, responsive evidence tables and text-equivalent SVG charts. A full-area native textarea overlays the feedback mirror; the mirror displays errors, caret and selection, but does not own editing. A text-only correction hint identifies the first mismatch without changing native/mirror geometry or adding another input bar. Show only previous/current/next context and keep the active line in view. style.css owns tokens; no new component framework.
## Accessibility
WCAG 2.2 AA target, not certification. Label the native textarea, expose concise target/instructions once and preserve native value/selection and visible focus. Errors use an underline as well as color. Keep skip link, keyboard-accessible controls and status announcements; never announce each glyph or timer tick. Reduced motion avoids animated scrolling. The user-approved local-completion boundary retains the original manual screen-reader/AT check as an untested release gate, not a pass. OS IME and complete rendered-state contrast verification also remain gaps; synthetic events and CSS zoom are not certification.
## Responsive behavior
Desktop max 1080px; collapse columns below 760px. At 390px navigation wraps, cards remain readable, tables scroll internally, words wrap. Target usable controls at 200% browser zoom; current no-overflow evidence uses CSS zoom, not browser-UI zoom.
## Interaction states
Explicit loading, empty history, unavailable recommendation/model/report, invalid URL fallback, incompatible retest, skipped corrupt records and failed-save retry/export. Legacy redirects preserve query intent for visible destination fallback feedback. Duration/layout/chooser lock during a run; restart keeps settings and obtains a new ID. Exceptional safety-stop retains partial text/metrics and offers keyboard-reachable diagnostic export/restart, never a normal saved result or trend point. Permanent validation failures retain export without retry; transient storage failures remain retryable. Guest data stays local. Loaded sessions work offline; do not promise offline reload.
## Content voice
Concise and specific: observed, predicted, experimental, General, Recommended, Manual. “Space advances words; Backspace corrects the current passage.” Explain that committed passages cannot be edited. Separate manual choice from an evidence-supported recommendation; never invent manual counts/scores. No-model warm baseline predictions do not imply Recommended is available. No claims that prediction accuracy demonstrates training efficacy.
## Implementation constraints
Vanilla TypeScript/Vite, semantic HTML, native DOM/CSS/SVG/IndexedDB. No new frontend dependencies, remote inference or key event upload. Retain edit reconstruction, first-pass timing exclusions and frozen predictions; exclude the terminal advancing space from metrics. New settings use flow-v1 and supported durations; legacy absent-mode records remain unchanged and 60s-only. Calibration, trends and retests require matching interaction/duration/layout/language/corpus and metric/schema versions. Finite caps: 16,384 insertions, 256 summaries, 600-character response and 1MiB stored-result JSON. Cache immutable summary byte sizes and check the current summary/metadata at passage commits and expiry, not full-history serialization per keystroke. Export-only stopped diagnostics preserve accepted evidence and may exceed the stored-result byte cap. Test the 120s/300WPM envelope and exceptional byte boundary rather than silently dropping diagnostics. Unit/type/build and explicitly invoked committed Chromium regression checks support local acceptance; final review and wider accessibility/device verification remain distinct gates. No lint script is configured.
