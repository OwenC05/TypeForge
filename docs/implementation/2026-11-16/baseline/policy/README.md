# P1 policy handoff

Recommended contract: [practice-policy-v1](../../../../../.omx/specs/typeforge-practice-policy-v1.md). Status: Stage 2A proposal ready for root's independent architecture/critical review and actual-Claude reconciliation; no production adaptive implementation.

Ten optional 30s assessment tests count completed valid participation, including ordinary mistakes and an unfinished final sentence. General/manual stays available throughout. Ten-test achievement is non-aging but re-derived from present source witnesses; target timing evidence uses a separate newest20/30-day window. A suggested pair needs 20 target/80 other intervals, four runs/prompts, three words, 25% full contrast, stable 10% half contrasts and a certified finite-prefix exposure plan. These are experimental product safeguards, not scientific optima or confidence levels. No passing target means General/manual, a valid outcome.

The contract checker validates its small declared JSON Schema subset and semantic threshold examples; it is not a general JSON Schema implementation. Fixtures alone do not prove an eventual IndexedDB migration, atomic revision integration, native input, actual exposure instrumentation, browser UI, accessibility, adherence, decision usefulness or learning improvement. Those remain future implementation/review/evaluation work, not hidden passing claims. No lint/typecheck/build is claimed for unchanged production source.

Source probe caveat: scripts pin hashes of current source/spec/artifacts and regenerate output. The static illustration is a finite plan probe, never an adaptive selector. Its 10/30/60 WPM budgets are artificial insertion slots; slow/errorful users can complete participation without any eligible timing. `br` is a feasible exposure example, `th/he` show checkpoint counterexamples, and `ag/au/zz` demonstrate valid General fallbacks.

Probe source hashes describe raw bytes at the recorded checkout; a CRLF-normalizing checkout can change them without changing text semantics. Regenerate on the integration checkout and inspect that provenance change rather than claiming raw-byte parity across line-ending conversions.
